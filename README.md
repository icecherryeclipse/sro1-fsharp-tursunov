### 1. Цель работы
Овладение навыками обработки и агрегации данных на функциональном языке программирования F#. Изучение и применение записей (records), кортежей (tuples), а также построение конвейеров обработки данных с помощью чистых функций и функций высшего порядка модуля `List` без использования изменяемых переменных (`mutable`) и циклов.

### 2. Описание данных
В качестве предметной области был выбран Вариант 3 — «Корзина продуктов». По согласованию с преподавателем данные были сгенерированы на основе реальных рыночных цен г. Алматы. 
*   **Период выборки:** с 01.10.2026 по 08.10.2026 (интервал — 1 неделя).
*   **Локации:** супермаркет Magnum, Базар «Зелёный» и супермаркет Small.
*   **Состав корзины:** 15 базовых товаров из 5 категорий (Молочное, Выпечка, Мясо, Овощи и фрукты, Бакалея).
*   **Объем данных:** 90 записей в формате CSV.

### 3. Мои предположения (до начала анализа)
1.  **Где корзина будет самой дешёвой?** Самая дешёвая корзина будет на Базаре из-за отсутствия больших наценок сетевого ритейла.
2.  **Разница в стоимости:** Разница между самым дорогим местом (Small) и самым дешёвым (Базар) составит около 12–15%.
3.  **Изменение за неделю:** Стоимость корзины слегка вырастет (на 1–2%) из-за сезонных колебаний.
